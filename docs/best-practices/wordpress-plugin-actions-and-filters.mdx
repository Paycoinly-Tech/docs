# Hook into Actions and Filters of Paycoinly Plugin

You can use third-party Wordpress plugins such as
- [WPCode](https://wordpress.org/plugins/insert-headers-and-footers/)
- [Code Snippets](https://wordpress.org/plugins/code-snippets/)

to easily add hooks into the above actions and filters without modifying your files or writing a full custom plugin.
